## Audit Findings

### What Works ✅
- **Data Collection:** 3,029,343 transactions, 68 DVNs, Oct '25 – Feb '26
- **DVN Profiles:** Metrics, charts, routes with latency
- **Fee Sampling:** On-chain DVNFeePaid decoding
- **Top Routes:** Pre-computed with volume, latency, success rate

### What's Broken ❌

#### 1. Stacks Missing Avg Latency (Regression)
- `EnhancedStacks` renders `stack.avgLatency` → always `null` → "N/A"
- `compute_dvn_stacks.js` never computes latency; `dvn_top_stacks` table has no `avg_latency` column
- `transactions.latency_seconds` has the raw data — just needs to be aggregated into stacks

#### 2. Search Returns Nothing for Major Institutional Tokens
- Search endpoint only checks `verified_oapps.json` (15 tokens)
- Does NOT touch `stargate-ecosystem-assets.json` (18,530 entries) or `manualRegistry.js`
- Institutions searching their own asset → "No results" → deal-breaker

#### 3. Volume Label Misleading
- Says "Lifetime Volume" but data = Oct '25 – Feb '26 (~4 months)

#### 4. Stacks Volume Mostly $0
- Only 15 OApps priced in `verified_oapps.json`

### DB Structure
- `transactions` — 3M rows, has `latency_seconds`, `oapp_address`, `amount_tokens`
- `dvn_attribution` — maps tx_hash → dvn_address
- `dvn_top_routes` — pre-computed per-DVN routes (HAS `avg_latency`)
- `dvn_top_stacks` — pre-computed stacks (MISSING `avg_latency`)
- `dvn_aggregate` — per-DVN summary metrics
- Data range: Oct 8, 2025 → Feb 2, 2026

### Running Processes
- Backend: `cd server && node server.js` (port 3001)
- Frontend: `npm start` (port 3000)
